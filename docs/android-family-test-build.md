## Install on Android

1. Download the `app-debug.apk` file from the workflow artifact.
2. Open the downloaded APK on the Android phone.
3. If Android asks, allow the browser or file manager to install unknown apps.
4. Review the app name and installation prompt, then install.
5. Open SIGNBRIDGE and test the text, speech, captions and camera-preview features.

Only install APKs from this repository's trusted Actions workflow. Android may
show a warning because this is a sideloaded debug build.

## What this build does and does not do

Available functions include the communication board, quick-help phrases,
browser text-to-speech, supported-browser speech captions, Call Assist message
preparation, local family recording and a camera preview.

The camera preview is **not** sign-language recognition. No trained ASL model
is connected to the live camera path. ASL is the pilot language setting; ISL
and BSL remain separate language tracks and are not interchangeable.

Call Assist prepares text and speech for a call and can open the phone dialler.
It does not hear or interpret audio from an ordinary cellular call. Full two-way
call interpretation requires a separately configured app-routed telephony
service and backend.

## Privacy and testing

Family Recorder is designed for local device use; do not upload family videos
to GitHub or share them without explicit consent. Check Android camera and
microphone permissions before testing those features. Browser speech-caption
availability depends on the browser and its speech service.

Report device model, Android version and reproducible issues without including
private recordings or family identifiers. Do not treat this debug build as a
validated medical, emergency or safety-critical interpreter.
